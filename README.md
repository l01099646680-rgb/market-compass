# Market Compass

국장·미장·크립토를 한 화면에서 분석하고, 장 마감 이후 매매 대응을 정리하기 위한 시장 분석 보조 웹사이트입니다.

## 현재 구현

- 국장·미장 마감 브리핑 UI
- 매매 조건 탐지 및 관심종목
- BTC·ETH·SOL 달러 현재가
- Binance 현물 5,000호가 기반 주요 매물대
- 현재가 위·아래 주요 가격대별 물량 및 달러 규모
- 60초 자동 갱신과 수동 새로고침
- 모바일 대응

현재 크립토 가격과 매물대는 실시간 데이터이며, 국장·미장 분석 수치는 아직 샘플입니다.

> 투자 판단을 돕기 위한 도구이며 매수·매도 신호를 보장하지 않습니다.
